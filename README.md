# Property OS UI

Property OS — Product UI, Design System, Mobile, Inspector and Admin visual implementation.

## Current slice

- Calm Premium design system
- RTL-first Persian / LTR-ready foundation
- 6 mobile reference screens: Splash, Login, OTP, Home, Property Detail, My City
- 3 admin reference screens: Dashboard, Users, Property Management
- Visual review board at `/#/design`

## Run locally

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:5173/#/design
```

## Build

```bash
npm run build
```
