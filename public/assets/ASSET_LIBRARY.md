# Property OS Asset Library

Production-friendly reusable assets live under `public/assets/`.

- `property-city/environment/property_city_district_arcade_pixel_v1.webp` — original premium pixel/arcade isometric property district; use for Atlas / My City, not operational alerts.
- `illustrations/onboarding/` — reserved for first-run role/scope illustrations.
- `illustrations/empty-states/` — reserved for contextual empty states.
- `icons/property/` — reserved for deterministic SVG property icons.
- `motion/` — reserved for reduced-motion-safe ambient assets.

Asset rule: visuals explain a property, role, state or progression. They are not generic decoration or a game loop.
