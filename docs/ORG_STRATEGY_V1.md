## 2. Decision rights

Use RAPID-like lightweight rule:

- Reversible + domain-owned → owner decides, documents afterwards
- Cross-domain → consult the other founder
- Irreversible/material → both approve
- Legal/security/money → both approve + specialist where needed

## 3. Hiring sequence

### Engineering
Hire when validated backlog consistently exceeds founder capacity.

### Customer Ops
Hire when user support regularly interrupts engineering or building onboarding cannot be founder-run.

### Growth
Hire after retention + paid conversion, not before.

### Field/Trust Ops
Hire/contract after inspection contribution margin is demonstrated.

## 4. Employment model

Early:
- founders
- targeted contractors
- specialist advisors

Before full-time hiring:
- IP assignment
- confidentiality
- access controls
- onboarding/offboarding
- compensation review cadence
- code review ownership
- least privilege
