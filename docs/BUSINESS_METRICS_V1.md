# Property OS — Business Metrics & Unit Economics v1

## North Star
**Monthly Active Managed Properties (MAMP)**

Definition:
distinct Property Records with >=1 meaningful management event in the calendar month.

Qualifying events:
- lease update
- role/invite
- document/evidence
- building charge
- maintenance
- verification
- listing/offer
- relevant finance record

Exclude:
- app open
- passive page view
- notification delivery

## KPI tree

### Acquisition
- qualified sessions
- signup conversion
- cost per signup
- cost per activated property
- channel mix

### Activation
- property created %
- time to first property
- activation %
- time to meaningful event
- invite sent %
- invite accepted %

### Engagement
- MAMP
- events/property/month
- collaborative property rate
- active building rate
- manager monthly active rate

### Retention
- D30/D90 account retention
- property retention
- building retention
- cohort retention by role

### Revenue
- MRR
- paid owners
- paid buildings
- ARPA
- expansion MRR
- churn
- gross revenue retention
- net revenue retention later

### Unit economics
- CAC
- onboarding cost
- support cost/account
- gross margin
- contribution margin
- payback months
- LTV/CAC (only after reliable cohorts)

### Trust
- evidence-backed %
- verification attach rate
- time to verify
- inspection rework %
- disputes / 1,000 verified properties

## Guardrails
- support tickets / 100 active properties
- notification opt-out
- security incidents
- failed payment rate
- data deletion SLA
- verification complaints
- manager collection mismatch rate

## Early-stage target philosophy
Do not invent target percentages before baseline.
First 8–12 weeks should establish distributions.
Then set targets based on cohort evidence.
